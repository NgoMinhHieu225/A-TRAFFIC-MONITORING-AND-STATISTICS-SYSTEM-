## 📌 Introduction
This project is an end-to-end **Real-time Traffic Monitoring and Statistics System** powered by Deep Learning. Utilizing **YOLOv8** for robust vehicle detection and tracking algorithms, the system identifies, classifies, and counts vehicles (cars, motorbikes, buses) to analyze traffic density and flow in real-time.

## ✨ Key Features
* **Real-time Vehicle Detection & Classification:** Detects motorbikes, cars, buses, and trucks using YOLOv8.
* **Object Tracking:** Tracks individual vehicle trajectories across video frames.
* **Traffic Counting:** Automatically counts vehicles crossing designated virtual lines/zones.
* **Traffic Flow Assessment:** Estimates real-time traffic density and routing statistics.

## 🛠️ Tech Stack
* **Deep Learning Framework:** YOLOv8 (by Ultralytics), PyTorch
* **Computer Vision:** OpenCV, NumPy
* **Language:** Python 3.10+
